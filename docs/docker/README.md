# Docker — документация

Продолжение урока: то же REST API библиотеки, но **в контейнерах**. Локальные venv и установленный на машину PostgreSQL больше не нужны — их заменяет Docker.

Материал разбит на этапы: теория → установка → команды → код → проверка.

## Как читать

1. Сначала этот файл — зачем Docker и что получится.
2. Затем строго по порядку шаги ниже — не переходите дальше, пока не отметили «✅ Готово».

Каждый технический блок устроен одинаково:

1. **Задача** — что должно получиться и зачем шаг нужен.
2. **Теория** — концепции, без которых команды «магия».
3. **Код** — что пишем в файлы / какие команды запускаем.
4. **Разбор** — зачем каждая конструкция.
5. **✅ Проверка** — что должно работать **сейчас**.

## Порядок шагов

| # | Файл | Что делаете | Теория |
|---|------|-------------|--------|
| 0 | *(этот файл)* | Обзор | — |

> **Правило:** не пишите Dockerfile «вперёд гайда». Сначала поставьте Docker и прогоните `hello-world`, потом упакуете приложение.

## Что уже должно быть

Этот раздел — **после** aiohttp-сборки и (желательно) FastAPI. Нужны `app/`, `alembic/`, `requirements.txt`, `.env`.

Клиент задачи 1 (`task_1_client`) в контейнер **не кладём** — он ходит на jsonplaceholder с вашей машины.

## Стек в Docker

| Компонент | Где крутится |
|-----------|----------------|
| FastAPI + Uvicorn | контейнер `app` (наш образ) |
| PostgreSQL 16 | контейнер `db` (образ `postgres:16`) |
| Alembic / сиды | при старте контейнера `app` |

**Старт:** [step-01-install.md](step-01-install.md)
