# Фоновый экспорт каталога — Celery

Продолжение после Docker: то же REST API библиотеки, плюс **фоновая задача**. `POST /exports` не собирает JSON в запросе — кладёт работу в очередь. Отдельный процесс (воркер) читает Postgres и пишет файл. Статус смотрим через `GET /exports/{task_id}`.

Материал разбит на этапы: теория → код → разбор → проверка.

## Как читать

1. Сначала [guide.md](guide.md) — зачем очередь, три процесса, карта API.
2. Затем строго по порядку шаги ниже — не переходите дальше, пока не отметили «✅ Готово».

Каждый технический блок устроен одинаково:

1. **Задача** — что должно получиться и зачем шаг нужен.
2. **Теория** — концепции, без которых код «магия».
3. **Код** — что пишем в файлы.
4. **Разбор** — зачем каждая конструкция.
5. **✅ Проверка** — команды / `curl` / логи воркера: что должно работать **сейчас**.
